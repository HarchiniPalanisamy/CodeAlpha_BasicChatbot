# Basic Chatbot using Python

## Description

This is a simple rule-based chatbot developed using Python.

The chatbot responds to predefined user messages such as greetings, questions, and exit commands.

## Features

* Responds to greetings
* Answers basic questions
* Continuous chat using loop
* Exit option using `bye`
* Beginner-friendly console application

## Technologies Used

* Python
* If-Elif Statements
* Loops
* Functions
* Input/Output

## Supported Commands

* hello
* how are you
* what is your name
* who created you
* what can you do
* bye

## How to Run

1. Install Python
2. Open the project folder
3. Run `Chatbot.py`
